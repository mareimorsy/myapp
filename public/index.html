  • FROM node:alpine

    Starts from the official Node.js image on Alpine Linux — a small footprint means faster pulls and fewer packages to patch.

  • COPY package*.json → RUN npm ci

    Dependencies are installed in their own layer, so rebuilds that only touch code reuse the cache.

  • USER node

    The app drops root privileges before starting. Check the “Running as” tile above.

  • HEALTHCHECK

    Probes /health so the runtime knows the app is actually serving, not just started.
